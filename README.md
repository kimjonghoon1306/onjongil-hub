# 온종일 허브

블로그 · 애드센스 · 부업 스터디 자동화 툴 모음 페이지

## 배포

GitHub 업로드 후 Vercel에서 Import → 바로 배포

## 관리자

- 기본 비밀번호: `0000`
- `app.js` 상단 `ADMIN_PW` 값 변경

## 툴 추가/수정/삭제

1. 사이트 접속
2. 우측 하단 `+` 버튼 클릭
3. 비밀번호 입력 → 관리자 모드 진입
4. 카드 추가 / 수정 / 삭제

## 파일 구조

```
onjongil-hub/
├── index.html   # 메인 페이지
├── style.css    # 스타일
├── app.js       # 기능 (툴 관리, 로컬스토리지)
└── vercel.json  # Vercel 설정
```
